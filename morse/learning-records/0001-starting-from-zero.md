# Starting from zero

At the start (2026-11-15), the learner knew no Morse beyond perhaps SOS, and hadn't memorised any visual dot/dash chart. This is an advantage: there's no chart habit to unlearn, so every character can be taught purely as sound at 20 WPM character speed from lesson 1, as Koch and Pierpont recommend.

**Implications**: Never show a dot/dash chart as a way to learn characters. Written patterns appear only as feedback after an answer, or in the printable reference.
