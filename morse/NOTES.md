# Notes

## Learner preferences
- Wants receiving and sending weighted **equally**.
- Practice budget: 10–15 min on most days. Keep every lesson inside that.
- Sends via keyboard/spacebar tapping in the browser.
- Finish line: whole alphabet and digits by ear at ~20 WPM character speed. No deadline.

## Teaching approach (working notes)
- Learn characters as **sounds**, never as visual dot/dash charts. Lessons play audio first and say it aloud as "dit"/"dah"; the written pattern is shown only after an answer, as feedback.
- Character speed fixed at 20 WPM from day one; slow down only the spacing between characters (Farnsworth) if needed.
- Introduce characters a few at a time (Koch-style): add a new one only once accuracy on the current set is ≥90%.
- One new character per lesson, following `Morse.ORDER`. The new one is the listening drill's `data-focus` (played ~50% of the time). Each lesson opens with a short recall warm-up on the previous set.
